# SEE Architecture

## Core layers

- Web UI: Arabic RTL audit workspace
- Application layer: audit workflows and permissions
- Domain layer: deterministic accounting and audit rules
- Evidence layer: provenance and trace graph
- AI Gateway: controlled model routing

## Main modules

1. Engagement Management
2. Controlled Import
3. Trial Balance Engine
4. Ledger Analytics
5. Materiality Engine
6. Risk Engine
7. Procedures Engine
8. Evidence Explorer
9. Workpapers
10. Review Gates
11. Reporting Studio
12. AI Audit Council

## Development rule
Use adapters and contracts. Do not duplicate deterministic audit engines without tests.
